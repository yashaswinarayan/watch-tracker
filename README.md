# ⌚ Automated Watch Deals & Restock Monitor

An automated tracking bot built with Python and GitHub Actions that monitors official storefronts for deep discounts and high-demand restocks, delivering real-time alerts straight to Telegram.

---

## 🚀 Features

* **Casio Deal Alert (`tracker.py`):** Monitors the authorized dealer catalog (`casiostore.bhawar.com`) and flags in-stock watches with discounts $\ge$ 60% off MRP.
* **HMT Restock Tracker (`hmt_tracker.py`):** Scrapes official HMT collections (Mechanical, Automatic, Quartz) to detect restocks of previously sold-out models.
* **Delhi Watch Company Monitor (`dwc_tracker.py`):** Polls the DWC catalog endpoint to send instant alerts the moment limited-batch watches become available.
* **Zero Infrastructure Overhead:** Powered entirely by GitHub Actions and scheduled triggers, requiring no dedicated server or always-on machine.
* **Instant Alerts:** Pushes clean, formatted notifications with direct purchase links to Telegram.

## 🛠️ Setup & Deployment

### 1. Telegram Bot Configuration
1. Message `@BotFather` on Telegram to create a bot and copy the **HTTP API Token**.
2. Message `@userinfobot` to retrieve your personal **Telegram Chat ID**.
3. Start a chat with your newly created bot so it has permission to send you messages.

### 2. GitHub Secrets
Navigate to **Settings** > **Secrets and variables** > **Actions** in this repository and add:

| Secret Name | Description |
|---|---|
| `TELEGRAM_BOT_TOKEN` | HTTP API token generated by BotFather |
| `TELEGRAM_CHAT_ID` | Numeric Telegram chat/user ID |

### 3. Execution Schedule
The workflow is configured via `.github/workflows/monitor.yml` and can be triggered via:
* **Workflow Dispatch:** Run manually from the **Actions** tab.
* **External Webhook:** Pinged via an external cron scheduler (e.g., `cron-job.org`) targeting the GitHub workflow dispatch API.
